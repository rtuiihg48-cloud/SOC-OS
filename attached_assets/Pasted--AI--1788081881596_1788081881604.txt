🧨 2. ЩО ТРЕБА ОБОВ’ЯЗКОВО ВИПРАВИТИ (ІНТЕГРАЦІЯ ПАДАЄ ТУТ)
Ось де зараз у тебе “майже продакшн, але ще не SaaS”:
❌ ПРОБЛЕМА 1: немає єдиного ingestion layer
Зараз:

API → processPipeline
👉 треба:

API → Queue → Pipeline Worker → DB → WS
Інакше:
немає масштабування
немає backpressure
не SaaS рівень
❌ ПРОБЛЕМА 2: memoryChain в синхронному потоці
Зараз:
кожен event = write hash chain sync
👉 треба:
або async write
або separate worker
Інакше:
latency росте лінійно
❌ ПРОБЛЕМА 3: WebSocket прямо в core
Це погано.
👉 правильніше:

core → emits event → transport layer (ws adapter)
❌ ПРОБЛЕМА 4: tenantId не enforced
Зараз:
просто поле
👉 треба:
middleware enforcement
context injection
❌ ПРОБЛЕМА 5: немає event normalization
Зараз:
TypeScript
event: string
👉 має бути:
TypeScript
{ type, source, severity, payload }
Інакше:
rules engine не масштабується
