Візуальні збіги
На скріншоті зображена помилка виконання NotFoundError: Failed to execute 'removeChild' on 'Node', яка виникає в процесі роботи інструменту збірки Vite (або під час оновлення сторінки через HMR — Hot Module Replacement).
Помилка українською мовою звучить як: "Не вдалося виконати 'removeChild' на 'Вузлі': Вузол, який потрібно видалити, не є дочірнім елементом цього вузла."
🔍 Чому виникає ця помилка?
Ця проблема є класичною для сучасних JavaScript-фреймворків (найчастіше React або Vue), які використовують віртуальне дерево елементів (Virtual DOM). Вона з'являється, коли фреймворк намагається видалити HTML-елемент зі сторінки, але цього елемента там уже немає або його структура була змінена стороннім скриптом.
Найпоширеніші причини:
Розширення браузера: Google Translate (або вбудований перекладач), AdBlock, сторонні плагіни автоматично модифікують HTML-код сторінки. Коли фреймворк намагається оновити інтерфейс, він "губиться" через змінену структуру.
Умовний рендеринг (Conditional Rendering): Некоректна робота з тернарними операторами чи логічними && в коді (особливо в React без використання унікальних ключів key).
Пряме втручання в DOM: Використання ванільного JavaScript (наприклад, document.getElementById().remove()) всередині компонентів фреймворку.
🛠️ Як це виправити?
1. Швидка перевірка (для користувача/розробника)
Вимкніть автоперекладач сторінок: Якщо у вас увімкнено автоматичний переклад сайту українською мовою в Chrome/Brave, вимкніть його для цього сайту. Це вирішує проблему у 90% випадків.
Відкрийте в режимі інкогніто: Перевірте роботу сайту в приватному вікні без розширень.
2. Виправлення в коді (якщо ви розробник)
Додайте унікальні ключі (key): Переконайтеся, що всі списки та елементи, які рендеряться динамічно, мають унікальний атрибут key.
Огорніть текстові вузли в теги: Замість чистого тексту всередині умовних операторів використовуйте теги <span> або <div>.
javascript
// Погано (може викликати помилку при перекладі браузером)
{isLoggedIn && "Вітаємо на сайті!"}

// Добре
{isLoggedIn && <span>Вітаємо на сайті!</span>}
Будьте обачні, використовуючи код.
3. Тимчасове приховування помилки у Vite
Як зазначено на самому скріншоті, ви можете вимкнути появу цього червоного вікна (overlay) у налаштуваннях Vite, щоб воно не заважало розробці. Для цього у файлі vite.config.ts (або .js) додайте наступний рядок:
typescript
export default defineConfig({
  server: {
    hmr: {
      overlay: false
    }
  }
})
Будьте обачні, використовуючи код.
